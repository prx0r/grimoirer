## Custom Studio

### What It Does

| Tool | What Customer Creates | Output |
|------|----------------------|--------|
| **Ring Studio** | Custom talisman ring | STL file → Cooksongold casting |
| **Sigil Studio** | Personal sigil design | SVG → engraved talisman |
| **Talisman Studio** | Custom amulet | STL → metal 3D print |
| **Plaque Studio** | Engraved display plaque | SVG → laser engraving |

### Studio Flow

```
1. Customer selects base design (ring, talisman, sigil)
2. Customer customizes (size, material, engraving, symbols)
3. Studio generates 3D preview
4. Customer approves design
5. Order placed with Cooksongold/Cloud Factory
6. Metal printed/cast, engraved, finished
7. Ships to customer (10-14 days)
```

### Mesh Upsell Chain

```
Customer buys: Custom ring (Cooksongold)
  → Mesh stored in Vault
  → Upsell: Ring display stand (Makr3D)
  → Upsell: Ring box (Alibaba kraft)
  → Upsell: Matching talisman
  → Upsell: Ring holder for desk

Customer buys: Sigil talisman
  → Mesh stored in Vault
  → Upsell: Talisman chain
  → Upsell: Altar display stand
  → Upsell: Matching wax seal
```
