## The Playbook

```
1. Ochema logo animation (2 seconds)
2. Video body (educational, story, or tutorial)
3. "This video inspired by our [product] at Ochema"
4. Product link in description + pinned comment
5. End screen: subscribe + product link
```

**Every video = content + soft sell. Never hard sell.**
