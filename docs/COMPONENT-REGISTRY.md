## The Companion Guide Concept

**We never instruct. We accompany.**

| Instead Of | We Provide |
|-----------|-----------|
| "How to cast a spell" | Historical context for the ritual |
| "Perform this exorcism" | What the original text says |
| "Use this to summon spirits" | Symbolism and correspondences |
| "Follow these steps" | Where to find the original source |

### Companion Guide Structure (16 pages)

```
Page 1: Title + historical context
Page 2-3: Who wrote this, when, why
Page 4-5: Structure overview (books, chapters)
Page 6-7: Key concepts explained
Page 8-9: Symbolism and correspondences
Page 10-11: Planetary hours / angel names (if relevant)
Page 12-13: Component list with supplier links
Page 14: "Where to find the original text"
Page 15: Further reading
Page 16: Ochema brand + charity note
```

**What's NOT in the guide:**
- Step-by-step ritual instructions
- "Do this to achieve that" language
- Promises of results
- Medical or psychological claims

**What IS in the guide:**
- Historical context
- Symbolism explained
- Correspondence tables
- Supplier links
- Further reading
- Honest disclaimers

## The Resource Positioning

### What Ochema Is

**Not:** A shop selling occult stuff.
**Not:** A profit-maximizing business.
**Is:** A resource people come to browse, learn, and form community.

### What That Means

| Element | Approach |
|---------|----------|
| **Content** | Free grimoire library, YouTube, spell guides |
| **Products** | Companion kits, not instruction manuals |
| **Pricing** | Fair, not maximum |
| **Charity** | 5% to chosen cause |
| **Transparency** | Every supplier linked |
| **Community** | App with birth charts, diaries, forums |
| **Language** | "Companion guide" not "instruction manual" |

### Revenue Target (Not Maximum Profit)

| Month | Revenue | Profit | Charity |
|-------|---------|--------|---------|
| 1 | $500 | $100 | $25 |
| 3 | $1,500 | $300 | $75 |
| 6 | $3,000 | $600 | $150 |
| 12 | $6,000 | $1,200 | $300 |

**We're not trying to get rich.** We're trying to build a resource that people trust and return to.

### The Flywheel

```
Free content (grimoires, YouTube, guides)
  → People discover Ochema
    → They browse products
      → They buy a companion kit
        → They join the community
          → They tell others
            → More people discover Ochema
              → Repeat
```

**Revenue funds the resource. The resource attracts community. Community sustains the revenue.**
