# Notoria Grammar — 4-week schedule (Sanskrit path)

**Cadence:** 3×/week min · **Session:** 25 min · **Art:** grammar

## Week 1 — Setup + first generals
| Day | Nota | Study |
|-----|------|-------|
| Mon | Devanagari / phoneme grid | Grade 0 row 1 (ka–ṅa) |
| Wed | same grid | row 1 recall without chart |
| Fri | matrika color map (PEDAGOGICAL) | row 2 + green-core pause |

| Day | Nota | Study |
|-----|------|-------|
| Mon | one sūtra fragment | pronounce + feel locus |
| Wed | sandhi gate sketch | one sandhi pair |
| Fri | grammar nota PD plate | reconstruct ka→ṅa from memory |

## Week 3 — Rhythm + planetary optional
| Day | Nota | Study |
|-----|------|-------|
| Mon | pratyahara card | expand 'ac' or 'hal' |
| Wed | phoneme tower | one contrast drill |
| Fri | longer inspection | 25–35 min block |

## Week 4 — Evaluate
| Day | Nota | Study |
|-----|------|-------|
| Mon | weakest locus | attack that only |
| Wed | strongest locus | teach-back one rule |
| Fri | any | weekly log review |

**Exit rule:** continue same cadence OR change one variable — not all three.
